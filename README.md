# Data-Privacy-Audit-on-Youtube
We conducted a data privacy audit of YouTube to analyze its data collection and processing practices, identify potential privacy risks, evaluate existing user privacy controls, and recommend measures to improve data privacy also the anticipated controversial AI age estimate system.
We also learned about cryptographic and data anonymisation techniques at last. We analysed a COPPA(Children's online privacy protection Act 2019) case after that case YouTube has introduce "Youtube for kids".
